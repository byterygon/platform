## Size and uncertainty

The experimental dual-codec build adds **984 gzip bytes** over a JSON-only build that explicitly removes raw CBOR implementations. This is not a production package-size promise. The standalone cbor-x comparator is 10768 gzip bytes.

Five independent trials alternate codec order for Node/browser codec runs. Rust and the separate Node transport runs have fixed order. Summary artifacts include p50/p95, trial ranges and seeded exploratory bootstrap intervals across only five trial p95 values. No p99 claims are made. Supplemental 256 KiB, 512 KiB and near-1 MiB controls have fewer samples and are excluded from adoption gates. All benchmark programs ran sequentially in bench.sh; the host was not an isolated performance machine.
